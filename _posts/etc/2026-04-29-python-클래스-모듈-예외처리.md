<h2 id="1-클래스와-객체">1. 클래스와 객체</h2>
<p>파이썬에서 <strong>객체(Object)</strong> 란 정의할 수 있는 모든 것을 의미한다.
<strong>클래스(Class)</strong> 는 그 객체를 찍어내는 틀이다.</p>
<pre><code class="language-python">class FourCal:
    def setdata(self, first, second):
        self.first = first
        self.second = second

    def add(self):
        return self.first + self.second

    def sub(self):
        return self.first - self.second

    def mul(self):
        return self.first * self.second

    def div(self):
        return self.first / self.second


a = FourCal()   # a라는 객체 생성
b = FourCal()   # b라는 객체 생성

a.setdata(4, 2)
b.setdata(3, 8)

print(a.add())  # 6
print(b.mul())  # 24</code></pre>
<h3 id="self란">self란??</h3>
<p><code>self</code>는 <strong>자기 자신을 가리키는 매개변수</strong>다.
<code>a.setdata(4, 2)</code> 를 호출하면 파이썬 내부에서는 <code>FourCal.setdata(a, 4, 2)</code> 처럼 동작한다.
그래서 메서드 정의에 파라미터가 3개(<code>self, first, second</code>)여도 호출할 땐 2개만 써도 된다.</p>
<pre><code>a.setdata(4, 2) 호출 시:
self  → a (자기 자신)
first → 4
second → 2

a.first = 4, a.second = 2 로 저장됨
b.first = 3, b.second = 8 로 따로 저장됨  ← a랑 b는 독립적!</code></pre><blockquote>
<p>💡 객체지향의 핵심: 같은 클래스로 만들었어도 각 객체는 '독립된 데이터'를 가진다.</p>
</blockquote>
<hr />
<h2 id="2-생성자-__init__">2. 생성자 <code>__init__</code></h2>
<p><strong>생성자(Constructor)</strong> 란 객체가 생성될 때 자동으로 호출되는 메서드다.
파이썬에서는 <code>__init__</code> 이라는 이름을 사용한다.</p>
<pre><code class="language-python">class FourCal:
    def __init__(self, first, second):  # 객체 생성 시 자동 실행!
        self.first = first
        self.second = second

    def add(self):
        return self.first + self.second


a = FourCal(4, 2)   # setdata() 따로 안 불러도 됨
print(a.add())       # 6</code></pre>
<p><code>setdata()</code>를 따로 호출하던 것을 생성자 하나로 처리할 수 있다.
<code>__init__</code> 처럼 앞뒤에 언더바(<code>_</code>)가 두 개씩 붙은 것은 파이썬이 미리 정해둔 <strong>매직 메서드(Magic Method)</strong> 다.</p>
<hr />
<h2 id="3-상속과-오버라이딩">3. 상속과 오버라이딩</h2>
<h3 id="1-상속-inheritance">1) 상속 (Inheritance)</h3>
<p>부모 클래스에 공통 기능을 정의하고, 자식 클래스가 그걸 물려받아 추가 기능만 구현한다.</p>
<pre><code class="language-python">class MoreFourCal(FourCal):   # FourCal을 상속받음
    def pow(self):
        return self.first ** self.second


a = MoreFourCal(4, 2)
print(a.pow())   # 16  ← 새로 추가한 기능
print(a.add())   # 6   ← 부모 클래스에서 물려받은 기능</code></pre>
<h3 id="2-오버라이딩-overriding">2) 오버라이딩 (Overriding)</h3>
<p>부모 클래스의 메서드를 자식 클래스에서 덮어쓰는 것.
오버라이딩하면 무조건 자식 클래스 쪽이 실행된다.</p>
<pre><code class="language-python">class SafeFourCal(FourCal):
    def div(self):              # 부모의 div()를 덮어씀
        if self.second == 0:
            return 0            # 0으로 나누면 0 반환 (에러 방지)
        else:
            return self.first / self.second


a = SafeFourCal(4, 0)
print(a.div())   # 0  ← 부모였으면 ZeroDivisionError 발생</code></pre>
<pre><code>상속 구조:
FourCal (부모)
├── MoreFourCal (자식) → pow() 추가
└── SafeFourCal (자식) → div() 오버라이딩</code></pre><blockquote>
<p>코드 읽기는 복잡해도 재사용성이 높아지는 게 객체지향의 핵심 장점이다.</p>
</blockquote>

<h2 id="4-모듈과-if-__name__--__main__">4. 모듈과 <code>if __name__ == &quot;__main__&quot;</code></h2>
<p><strong>모듈(Module)</strong> 이란 함수, 클래스 등을 저장해둔 <code>.py</code> 파일이다.
라이브러리와 같은 개념이라고 보면 된다.</p>
<pre><code class="language-python"># mod1.py
def add(a, b):
    return a + b

def sub(a, b):
    return a - b

if __name__ == &quot;__main__&quot;:
    print(add(1, 4))
    print(sub(4, 2))</code></pre>
<h3 id="if-__name__--__main__-이-왜-필요한가"><code>if __name__ == &quot;__main__&quot;</code> 이 왜 필요한가?</h3>
<pre><code class="language-python"># 조건문 없이 그냥 print 쓰면?
def add(a, b): return a + b
print(add(1, 4))  # 테스트용 코드

# → 다른 파일에서 from mod1 import add 하는 순간
#   원치 않는 5가 화면에 출력돼버림!</code></pre>
<table>

<tr>
<th>상황</th>

</tr>

<tbody><tr>

<td><code>&quot;__main__&quot;</code></td>
<td>✅ 실행됨</td>
</tr>
<tr>

<td><code>&quot;mod1&quot;</code></td>

</tr>
</tbody></table>
<pre><code class="language-python"># main.py
from mod1 import add, sub

print(add(3, 5))   # 8 — 함수만 깔끔하게 가져옴</code></pre>
<blockquote>
<p><strong>직접 실행할 때는 테스트 결과를 보여주고,</strong>
<strong>다른 파일에서 불러올 땐 기능(함수)만 조용히 제공한다.</strong>
이게 일회용 코드와 재사용 가능한 부품의 차이다.</p>
</blockquote>

<h2 id="5-패키지">5. 패키지</h2>
<p><strong>패키지(Package)</strong> 는 관련 있는 모듈들을 모아놓은 폴더다.
모듈이 '파일'이라면 패키지는 '폴더'다.</p>
<pre><code>game/                  ← 패키지 (폴더)
├── __init__.py        ← 패키지임을 알리는 파일
├── sound/
│   ├── __init__.py
│   └── echo.py        ← 모듈
└── graphic/
    ├── __init__.py
    └── render.py      ← 모듈</code></pre><pre><code class="language-python"># 패키지 내 모듈 불러오기
from game.sound import echo
from game.graphic.render import draw

# 상대 경로 표기
from .  import echo     # '.'  = 현재 디렉토리
from .. import something # '..' = 상위 디렉토리</code></pre>
<blockquote>
<p>코드 짜기 전에 <strong>디렉토리 구조를 먼저 설계</strong>하는 습관이 중요하다.
큰 프로젝트일수록 패키지 구조가 유지보수의 핵심이 된다.</p>
</blockquote>

<h2 id="6-예외처리-tryexcept">6. 예외처리 try/except</h2>
<p>프로그램 실행 중 오류가 발생해도 강제 종료되지 않도록 처리하는 방법이다.</p>
<h3 id="기본-구조">기본 구조</h3>
<pre><code class="language-python">try:
    4 / 0
except ZeroDivisionError as e:
    print(e)   # division by zero</code></pre>
<h3 id="try--except--else--finally">try / except / else / finally</h3>
<pre><code class="language-python">try:
    age = int(input('나이를 입력하세요: '))   # 입력값 기본은 문자열 → int 변환 필요
except:
    print('입력이 정확하지 않습니다.')
else:
    # 예외가 발생하지 않았을 때만 실행
    if age &lt;= 18:
        print(&quot;미성년자는 출입금지입니다.&quot;)
    else:
        print('환영합니다.')
finally:
    # 예외 발생 여부와 상관없이 항상 실행
    print('프로그램을 종료합니다.')</code></pre>
<blockquote>
<p>⚠️ <code>input()</code>으로 받은 값은 기본적으로 <strong>문자열(str)</strong> 이다.
숫자로 사용하려면 <code>int()</code> 또는 <code>float()</code> 변환이 필요하다.</p>
</blockquote>
<h3 id="직접-예외-만들기-사용자-정의-예외">직접 예외 만들기 (사용자 정의 예외)</h3>
<pre><code class="language-python">class MyError(Exception):
    def __str__(self):
        return &quot;허용되지 않는 별명입니다.&quot;


def say_nick(nick):
    if nick == '바보':
        raise MyError()   # 직접 예외를 발생시킴
    print(nick)


try:
    say_nick(&quot;천사&quot;)   # 천사 출력
    say_nick(&quot;바보&quot;)   # MyError 발생!
except MyError as e:
    print(e)           # 허용되지 않는 별명입니다.</code></pre>

<h2 id="7-응용-복습-해보기스스로-직접-해본-내용들">7. 응용 복습 해보기(스스로 직접 해본 내용들)</h2>
<h3 id="문제-1-fourcal에-예외처리-결합하기">문제 1. FourCal에 예외처리 결합하기</h3>
<p>수업에서 배운 클래스와 예외처리를 합쳐봤다.</p>
<pre><code class="language-python">class SafeFourCal:
    def __init__(self, first, second):
        self.first = first
        self.second = second

    def div(self):
        try:
            return self.first / self.second
        except ZeroDivisionError:
            return &quot;0으로 나눌 수 없습니다.&quot;

    def sqrt(self):
        try:
            if self.first &lt; 0:
                raise ValueError(&quot;음수의 제곱근은 실수 범위에서 존재하지 않습니다.&quot;)
            return self.first ** 0.5
        except ValueError as e:
            return str(e)


a = SafeFourCal(9, 0)
print(a.div())    # 0으로 나눌 수 없습니다.

b = SafeFourCal(-4, 1)
print(b.sqrt())   # 음수의 제곱근은 실수 범위에서 존재하지 않습니다.

c = SafeFourCal(9, 1)
print(c.sqrt())   # 3.0</code></pre>
<blockquote>
<p>클래스 안에서 예외처리를 직접 담당하면 호출하는 쪽 코드가 훨씬 깔끔해진다.</p>
</blockquote>

<h3 id="문제-2-모듈-분리-실습">문제 2. 모듈 분리 실습</h3>
<p>수업 내용을 실제로 파일 두 개로 나눠서 실행해봤다.</p>
<pre><code class="language-python"># calculator.py
def add(a, b): return a + b
def sub(a, b): return a - b
def mul(a, b): return a * b
def div(a, b): return a / b if b != 0 else None

if __name__ == &quot;__main__&quot;:
    print(&quot;테스트:&quot;, add(1, 2))   # 직접 실행 시에만 출력</code></pre>
<pre><code class="language-python"># main.py
from calculator import add, sub, mul, div

results = {
    &quot;덧셈&quot;: add(10, 3),
    &quot;뺄셈&quot;: sub(10, 3),
    &quot;곱셈&quot;: mul(10, 3),
    &quot;나눗셈&quot;: div(10, 3),
}

for name, val in results.items():
    print(f&quot;{name}: {val}&quot;)</code></pre>
<p>출력:</p>
<pre><code>덧셈: 13
뺄셈: 7
곱셈: 30
나눗셈: 3.3333333333333335</code></pre><blockquote>
<p><code>calculator.py</code>를 직접 실행하면 테스트 결과가 나오고,
<code>main.py</code>에서 import 하면 테스트 코드는 실행되지 않는다.
<code>if __name__ == &quot;__main__&quot;:</code>의 동작을 직접 눈으로 확인했다.</p>
</blockquote>

<h3 id="문제-3-상속-체인-확장">문제 3. 상속 체인 확장</h3>
<p>수업에서 본 <code>FourCal → MoreFourCal</code> 구조를 한 단계 더 확장해봤다.</p>
<pre><code class="language-python">class FourCal:
    def __init__(self, first, second):
        self.first = first
        self.second = second
    def add(self): return self.first + self.second
    def div(self): return self.first / self.second


class MoreFourCal(FourCal):
    def pow(self): return self.first ** self.second


class ScientificCal(MoreFourCal):   # 손자 클래스!
    def mod(self): return self.first % self.second   # 나머지
    def div(self):                                    # 오버라이딩
        if self.second == 0:
            return &quot;정의되지 않음&quot;
        return round(self.first / self.second, 4)    # 소수점 4자리


calc = ScientificCal(10, 3)
print(calc.add())   # 13     ← FourCal에서 상속
print(calc.pow())   # 1000   ← MoreFourCal에서 상속
print(calc.mod())   # 1      ← ScientificCal 자체 기능
print(calc.div())   # 3.3333 ← 오버라이딩된 div</code></pre>
<pre><code>상속 체인:
FourCal
  └── MoreFourCal (pow 추가)
        └── ScientificCal (mod 추가, div 오버라이딩)</code></pre><blockquote>
<p>클래스를 계층적으로 쌓아가는 구조가 어떻게 동작하는지 확인할 수 있었다.</p>
</blockquote>
