<h2 id="구현-내용">구현 내용</h2>
<h3 id="1-댓글-조회---indexjs">1. 댓글 조회 - index.js</h3>
<p>기존 게시글 상세 라우터에 댓글 쿼리를 추가했다.
기존엔 게시글만 불러왔는데, 댓글까지 같이 가져와서 post.ejs로 넘겨줘야 한다.</p>
<p><strong>수정 전</strong></p>
<pre><code class="language-javascript">app.get('/posts/:postsId', function(req, res){
    const postId = req.params.postsId;

    db.query(
        &quot;UPDATE posts SET view_count = view_count + 1 WHERE post_id = ?&quot;,
        [postId],
        function() {
            db.query(
                &quot;SELECT * FROM posts WHERE post_id = ?&quot;,
                [postId],
                function(err, post){
                    res.render('post', {post: post[0]});
                }
            );
        }
    );
});</code></pre>
<p><strong>수정 후</strong></p>
<pre><code class="language-javascript">app.get('/posts/:postsId', function(req, res){
    const postId = req.params.postsId;

    db.query(
        &quot;UPDATE posts SET view_count = view_count + 1 WHERE post_id = ?&quot;,
        [postId],
        function() {
            db.query(
                &quot;SELECT * FROM posts WHERE post_id = ?&quot;,
                [postId],
                function(err, post){
                    db.query(
                        &quot;SELECT * FROM comments WHERE post_id = ?&quot;,
                        [postId],
                        function(err, comments){
                            res.render('post', { post: post[0], comments: comments });
                        }
                    );
                }
            );
        }
    );
});</code></pre>
<p>조회수 증가 → 게시글 조회 → 댓글 조회 순서로 쿼리를 중첩해서 처리한다.
콜백 지옥(callback hell)이긴 한데, 수업 수준에선 이 정도로 충분하다.</p>

<h3 id="2-댓글-작성---indexjs">2. 댓글 작성 - index.js</h3>
<p>원래 <code>POST /contents</code> 가 비어있었다. 여기에 INSERT 쿼리를 추가했다.</p>
<pre><code class="language-javascript">app.post('/contents', function(req, res){
    const { content, post_id } = req.body;

    db.query(
        &quot;INSERT INTO comments(post_id, user_id, content) VALUES(?, 1, ?)&quot;,
        [post_id, content],
        function(err, result){
            if(err) return res.send('오류!');
            res.redirect('/posts/' + post_id);
        }
    );
});</code></pre>
<ul>
<li><code>post_id</code>는 폼에서 hidden input으로 넘겨받는다</li>
<li><code>user_id</code>는 아직 로그인 기능이 없어서 임시로 1번 고정</li>
<li>댓글 등록 후 해당 게시글 페이지로 redirect</li>
</ul>

<h3 id="3-화면-구성---postejs">3. 화면 구성 - post.ejs</h3>
<p>게시글 본문 아래에 댓글 목록과 작성 폼을 추가했다.</p>
<pre><code class="language-html">&lt;%- include('common/header') %&gt;
&lt;style&gt;
    .content {
        padding: 10px;
        font-family: '맑은 고딕';
    }
&lt;/style&gt;

&lt;!-- 게시글 본문 --&gt;
&lt;article&gt;
    &lt;h5&gt;&lt;%=post.title%&gt;&lt;/h5&gt;
    &lt;pre class=&quot;content&quot;&gt;&lt;%=post.content%&gt;&lt;/pre&gt;
    &lt;div style=&quot;text-align: right;&quot;&gt;
        &lt;a href=&quot;/&quot;&gt;홈 화면으로&lt;/a&gt;
    &lt;/div&gt;
&lt;/article&gt;

&lt;!-- 댓글 영역 --&gt;
&lt;article&gt;
    &lt;h5&gt;댓글&lt;/h5&gt;

    &lt;!-- 댓글 목록 --&gt;
    &lt;% comments.forEach(function(comment){ %&gt;
        &lt;div style=&quot;border-bottom: 1px solid #eee; padding: 8px 0;&quot;&gt;
            &lt;p style=&quot;margin:0&quot;&gt;&lt;%= comment.content %&gt;&lt;/p&gt;
            &lt;small style=&quot;color:gray&quot;&gt;&lt;%= comment.created_at %&gt;&lt;/small&gt;
        &lt;/div&gt;
    &lt;% }) %&gt;

    &lt;!-- 댓글 작성 폼 --&gt;
    &lt;form action=&quot;/contents&quot; method=&quot;POST&quot; style=&quot;margin-top:15px;&quot;&gt;
        &lt;input type=&quot;hidden&quot; name=&quot;post_id&quot; value=&quot;&lt;%= post.post_id %&gt;&quot;&gt;
        &lt;input type=&quot;text&quot; name=&quot;content&quot; placeholder=&quot;댓글을 입력하세요&quot; style=&quot;width:80%&quot;&gt;
        &lt;button type=&quot;submit&quot;&gt;등록&lt;/button&gt;
    &lt;/form&gt;
&lt;/article&gt;

&lt;%- include('common/footer') %&gt;</code></pre>
<p><code>comments.forEach</code>로 댓글 목록을 순서대로 뿌려주고,
폼의 hidden input에 <code>post_id</code>를 담아서 서버로 같이 전송한다.</p>

<h2 id="서버-상시-실행-세팅-forever">서버 상시 실행 세팅 (forever)</h2>
<p>라즈베리파이에서 PuTTY로 <code>node index.js</code> 실행하면,
PuTTY 창 닫을 때 서버도 같이 꺼진다.</p>
<p>이걸 해결하려면 <strong>forever</strong> 를 쓰면 된다.</p>
<pre><code class="language-bash"># forever로 서버 시작
sudo forever start index.js

# 실행 중인 목록 확인
sudo forever list

# 서버 재시작 (코드 수정 후)
sudo forever restart index.js

# 서버 중지
sudo forever stop index.js</code></pre>
<p>이렇게 하면 PuTTY를 꺼도 라즈베리파이가 켜져 있는 동안은 서버가 계속 돌아간다.</p>
<blockquote>
<p>⚠️ 라즈베리파이를 재부팅하면 forever도 꺼진다. 재부팅 후엔 다시 <code>sudo forever start index.js</code> 해줘야 한다.</p>
</blockquote>
