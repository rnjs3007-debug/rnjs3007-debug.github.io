<h2 id="1-자주-나오는-핵심-패턴-5가지">1. 자주 나오는 핵심 패턴 5가지</h2>
<p>C언어 기초 문제의 대부분을 이 5가지 패턴이 커버한다!</p>
<pre><code class="language-c">// 패턴 1 — 자리수 추출
while (num &gt; 0) {
    digit = num % 10;
    num /= 10;
}

// 패턴 2 — 문자열 순회
for (i = 0; ch[i] != '\0'; i++) { }

// 패턴 3 — 최댓값 찾기
max = arr[0];
for (i = 1; i &lt; n; i++)
    if (arr[i] &gt; max) max = arr[i];

// 패턴 4 — swap
temp = a;
a = b;
b = temp;

// 패턴 5 — flag + break
flag = FALSE;
for (...) {
    if (조건) { flag = TRUE; break; }
}</code></pre>
<blockquote>
<p>5가지 패턴은 무조건 익혀두기! (중요함!)</p>
</blockquote>

<h2 id="2-함수function-기본-개념">2. 함수(Function) 기본 개념</h2>
<p>함수를 쓰면 <code>main</code> 함수가 짧아지고, <strong>가독성과 재사용성</strong>이 높아진다.</p>
<h3 id="1-반환값이-있는-함수">1) 반환값이 있는 함수</h3>
<pre><code class="language-c">int add(int a, int b) {
    int result = a + b;
    return result;  // main에 값을 돌려준다
}

int main(void) {
    int a = add(1, 2);
    printf(&quot;%d\n&quot;, a);
    return 0;
}</code></pre>
<ul>
<li><code>int add(...)</code> → 정수를 반환할 때</li>
<li><code>float add(...)</code> → 실수를 반환할 때 (나눗셈 결과 등)</li>
<li>반환값이 있으면 <strong>무조건</strong> 반환 타입을 앞에 써야 한다!</li>
</ul>
<h3 id="2-반환값이-없는-함수-void">2) 반환값이 없는 함수 (void)</h3>
<pre><code class="language-c">void printMenu(void) {
    printf(&quot;1. 지도 보기\n&quot;);
    printf(&quot;2. 게임 시작\n&quot;);
}

int main(void) {
    printMenu();
    return 0;
}</code></pre>
<h3 id="3-매개변수parameter-vs-인자argument">3) 매개변수(Parameter) vs 인자(Argument)</h3>
<pre><code class="language-c">void printMenu(int menu)  // ← 이게 매개변수(Parameter)
{
    if (menu == 1) {
        printf(&quot;지도 화면\n&quot;);
    }
}

int main(void) {
    printMenu(1);  // ← 이게 인자(Argument)
    return 0;
}</code></pre>
<blockquote>
<p>파라미터 이름은 인자 이름과 달라도 된다.</p>
</blockquote>

<h3 id="4-사칙연산-함수-예시-switch-활용">4) 사칙연산 함수 예시 (switch 활용)</h3>
<pre><code class="language-c">int minus(int _num1, int _num2) { return _num1 - _num2; }
int add(int _num1, int _num2)   { return _num1 + _num2; }

int main(void) {
    int num1, num2;
    char op;

    while (1) {
        printf(&quot;수식 입력: &quot;);
        scanf(&quot; %d %c %d&quot;, &amp;num1, &amp;op, &amp;num2);

        switch (op) {
            case '+': printf(&quot;%d\n&quot;, add(num1, num2));   break;
            case '-': printf(&quot;%d\n&quot;, minus(num1, num2)); break;
        }
    }
    return 0;
}</code></pre>
<blockquote>
<p>C언어는 <strong>절차 지향</strong> 언어라 호출하는 함수는 <code>main</code>보다 위에 있어야 한다.
만약 아래에 정의할 경우, <code>main</code> 위에 <strong>함수 선언(프로토타입)</strong> 을 먼저 써줘야 한다.</p>
</blockquote>
<pre><code class="language-c">int minus(int, int);   // 프로토타입 선언 (변수명 생략 가능!)
int add(int, int);

int main(void) { ... }

int minus(int a, int b) { return a - b; }
int add(int a, int b)   { return a + b; }</code></pre>

<h2 id="4-재귀함수-recursive-function">4. 재귀함수 (Recursive Function)</h2>
<p>자기 자신을 호출하는 함수. 이론적으로 중요하지만 자주 쓰이진 않는다.</p>
<h3 id="팩토리얼-예시">팩토리얼 예시</h3>
<pre><code class="language-c">int f(int n) {
    if (n &gt; 1)
        return n * f(n - 1);  // 자기 자신 호출!
    return n;
}
// f(3) → 3 * f(2) → 3 * 2 * f(1) → 3 * 2 * 1 = 6</code></pre>
<blockquote>
<p>반복문으로도 동일한 결과를 낼 수 있다!</p>
</blockquote>
<pre><code class="language-c">int f(int n) {
    int result = 1;
    for (int i = 1; i &lt;= n; i++)
        result *= i;
    return result;
}</code></pre>

<h2 id="5-2차원-배열-활용">5. 2차원 배열 활용</h2>
<p>게임 맵, 행렬 등 <strong>여러 값을 동시에 저장</strong>할 때 사용한다.</p>
<h3 id="1-행열-합계-구하기">1) 행/열 합계 구하기</h3>
<pre><code class="language-c">int map[3][3] = {
    {1, 2, 3},
    {4, 5, 6},
    {7, 8, 9}
};

// 행 합계
for (int i = 0; i &lt; 3; i++) {
    int sumr = 0;
    for (int j = 0; j &lt; 3; j++)
        sumr += map[i][j];
    printf(&quot;%d행 합계: %d\n&quot;, i, sumr);
}

// 열 합계
for (int j = 0; j &lt; 3; j++) {
    int sumc = 0;
    for (int i = 0; i &lt; 3; i++)
        sumc += map[i][j];
    printf(&quot;%d열 합계: %d\n&quot;, j, sumc);
}</code></pre>
<blockquote>
<p> 열 합계 루프에서 <code>sumc = map[i][j]</code> 가 아닌 <code>sumc += map[i][j]</code> 로 써야 한다! (실수하기 쉬운 포인트)</p>
</blockquote>
<h3 id="2-최댓값--인덱스-찾기">2) 최댓값 + 인덱스 찾기</h3>
<pre><code class="language-c">int max = map[0][0];
int maxI = 0, maxJ = 0;

for (int i = 0; i &lt; 3; i++) {
    for (int j = 0; j &lt; 3; j++) {
        if (max &lt; map[i][j]) {
            max = map[i][j];
            maxI = i;
            maxJ = j;
        }
    }
}
printf(&quot;최댓값: %d, 위치: [%d][%d]\n&quot;, max, maxI, maxJ);</code></pre>
<h3 id="3-행렬-90도-회전">3) 행렬 90도 회전</h3>
<pre><code class="language-c">void rotate90(int m[3][3]) {
    // 1단계: 대각선 대칭 (행↔열 교환)
    for (int i = 0; i &lt; 3; i++)
        for (int j = i + 1; j &lt; 3; j++) {
            int temp = m[i][j];
            m[i][j] = m[j][i];
            m[j][i] = temp;
        }

    // 2단계: 좌우 대칭
    for (int i = 0; i &lt; 3; i++) {
        int temp = m[i][0];
        m[i][0] = m[i][2];
        m[i][2] = temp;
    }
}</code></pre>
<blockquote>
<p> <code>rotate90</code>을 두 번 호출하면 → 180도 회전한다. 다른 추가방법도 조금더 고민해보기.</p>
</blockquote>

<h2 id="6-실전-문제들">6. 실전 문제들</h2>
<h3 id="1-중복-없는-난수-배열-만들기">1) 중복 없는 난수 배열 만들기</h3>
<p>핵심은 <code>isCheck</code> 함수로 중복 여부를 먼저 확인하는 것!</p>
<pre><code class="language-c">int isCheck(int arr[], int count, int num) {
    for (int i = 0; i &lt; count; i++) {
        if (arr[i] == num)
            return TRUE;
    }
    return FALSE;
}

void makeRandomArray(int arr[], int size) {
    int count = 0;
    while (count &lt; size) {
        int num = rand() % 10 + 1;  // 1~10 난수
        if (isCheck(arr, count, num) == FALSE) {
            arr[count] = num;
            count++;
        }
    }
}</code></pre>
<blockquote>
<p><code>count</code>가 <strong>현재 저장된 개수</strong> 이자 <strong>다음 저장할 인덱스</strong> 역할을 동시에 한다!</p>
</blockquote>

while (count &lt; 3) {
    int num = rand() % 10;
    if (isCheck(computer, count, num) == FALSE) {

// strike / ball 판정
do {
    strike = 0; ball = 0;

        if (computer[i] == user[i]) strike++;

        for (int j = 0; j &lt; 3; j++) {
            if (i == j) continue;  // 같은 자리면 건너뜀
            if (computer[i] == user[j]) ball++;
        }

    printf(&quot;%d strike %d ball\n&quot;, strike, ball);

} while (strike != 3);</code></pre>

<h3 id="3-updown-게임">3) Up/Down 게임</h3>
<pre><code class="language-c">int main(void) {
    srand((unsigned int)time(NULL));

    int answer = rand() % 100 + 1;  // 1~100 난수
    int input = 0;

    do {
        printf(&quot;숫자 입력(1~100): &quot;);
        scanf(&quot;%d&quot;, &amp;input);

        if (input &lt; answer)      printf(&quot;UP!\n&quot;);
        else if (input &gt; answer) printf(&quot;DOWN!\n&quot;);

    } while (input != answer);

    printf(&quot;정답!\n&quot;);
    return 0;
}</code></pre>
