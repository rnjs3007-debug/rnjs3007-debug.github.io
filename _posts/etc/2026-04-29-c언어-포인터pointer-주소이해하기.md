<h2 id="void-return">void-return</h2>
<h2 id="1-void-함수의-return">1. void 함수의 return</h2>
<p><code>void</code> 함수에서 <code>return</code>은 <strong>반환값 없이 함수를 즉시 종료</strong>하는 용도로 쓸 수 있다.</p>
<pre><code class="language-c">void func(int a) {
    if (a == 0)
        return;   // 값 없이 그냥 빠져나옴 — 이건 OK!
    else {
        // 로직 처리
    }
}</code></pre>
<blockquote>
<p><code>void</code>는 &quot;반환값이 없다&quot;는 뜻이지, <code>return</code> 자체를 못 쓴다는 게 아님.
조기 종료(early exit) 패턴으로 자주 활용된다.</p>
</blockquote>
<hr />
<h2 id="왜-포인터가-필요한가">왜-포인터가-필요한가</h2>
<h2 id="2-왜-포인터가-필요한가">2. 왜 포인터가 필요한가?</h2>
<p>아래 코드를 먼저 보자.</p>
<pre><code class="language-c">void func(int num1, int num2) {
    num1 = 3;
    num2 = 4;
}

int main(void) {
    int a = 1, b = 2;
    func(a, b);
    printf(&quot;%d %d\n&quot;, a, b);  // 출력: 1 2
    return 0;
}</code></pre>
<p><code>a</code>와 <code>b</code>는 그대로 <strong>1과 2</strong>다. 왜?</p>
<pre><code>main의 a (0x001) → 값: 1
main의 b (0x002) → 값: 2

func 호출 시:
num1 = a의 복사본 → 3으로 바꿔도 원본 a는 그대로
num2 = b의 복사본 → 4으로 바꿔도 원본 b는 그대로
함수 끝나면 num1, num2 사라짐!</code></pre><p><strong>함수 안에서 원본 값을 바꾸고 싶다면 → 주소를 넘겨야 한다.</strong>
(포인터가 필요한 이유)</p>
<hr />
<h2 id="포인터-기본">포인터-기본</h2>
<h2 id="3-포인터-변수-기본-개념">3. 포인터 변수 기본 개념</h2>
<blockquote>
<p><strong>포인터(Pointer)란: 주소(메모리 주소)를 저장하기 위한 변수</strong></p>
</blockquote>
<pre><code>메모리 그림:

주소       값
0x001  →  [ 3 ]   ← int a = 3;
0x005  →  [0x001] ← int* b = &amp;a;  (b는 a의 주소를 저장!)</code></pre><pre><code class="language-c">int main(void) {
    int a = 3;
    int* b = &amp;a;            // b는 a의 주소를 저장하는 포인터

    printf(&quot;%d\n&quot;, a);      // 3    — a의 값
    printf(&quot;0x%u\n&quot;, b);   // 주소값 출력 (예: 0x001)
    printf(&quot;%d\n&quot;, *b);    // 3    — b가 가리키는 곳의 값 (역참조)

    return 0;
}</code></pre>

<h2 id="4-call-by-value-vs-call-by-reference">4. Call by Value vs Call by Reference</h2>
<h3 id="call-by-value-값-복사">Call by Value (값 복사)</h3>
<pre><code class="language-c">void func(int num1, int num2) {
    *num1 = 3;  // 복사본만 바뀜, 원본 무관
}</code></pre>
<h3 id="call-by-reference-주소-전달">Call by Reference (주소 전달)</h3>
<pre><code class="language-c">void func(int *num1, int *num2) {
    *num1 = 3;  // num1이 가리키는 원본을 직접 수정!
    *num2 = 4;
}

int main(void) {
    int a = 1, b = 2;
    func(&amp;a, &amp;b);           // 주소를 넘긴다
    printf(&quot;%d %d\n&quot;, a, b);  // 출력: 3 4
    return 0;
}</code></pre>
<pre><code>함수 내부:
int* num1 = 0x001  ← a의 주소
int* num2 = 0x002  ← b의 주소
*num1 = 3  →  0x001 위치의 값을 3으로 직접 수정!</code></pre><hr />
<h2 id="5-포인터로-swap-구현하기">5. 포인터로 swap 구현하기</h2>
<h3 id="❌-call-by-value--원본-안-바뀜">❌ Call by Value — 원본 안 바뀜</h3>
<pre><code class="language-c">void swap_val(int num1, int num2) {
    int temp = num1;
    num1 = num2;
    num2 = temp;
    // 복사본끼리만 교환됨. 원본은 그대로.
}</code></pre>
<h3 id="✅-call-by-reference--원본이-바뀜">✅ Call by Reference — 원본이 바뀜</h3>
<pre><code class="language-c">void swap_ref(int *num1, int *num2) {
    int temp = *num1;
    *num1 = *num2;
    *num2 = temp;
}

int main(void) {
    int a = 1, b = 2;
    swap_ref(&amp;a, &amp;b);
    printf(&quot;%d %d\n&quot;, a, b);  // 출력: 2 1
    return 0;
}</code></pre>
<pre><code>swap_ref 내부 동작:
temp  = *num1 = 1
*num1 = *num2 = 2   → a가 2가 됨
*num2 = temp  = 1   → b가 1이 됨</code></pre><blockquote>
<p>💡 swap은 정렬 알고리즘(버블정렬 등)의 핵심 연산이다.
포인터 없이는 제대로 된 swap이 불가능하다!</p>
</blockquote>
<hr />
<h2 id="6-배열과-포인터의-관계">6. 배열과 포인터의 관계</h2>
<blockquote>
<p><strong>배열의 이름은 곧 첫 번째 원소의 주소이다!</strong></p>
</blockquote>
<pre><code class="language-c">int a[5] = {1, 2, 3, 4, 5};
int *p = a;         // int *p = &amp;a[0]; 와 완전히 동일!

printf(&quot;%d\n&quot;, p[0]);    // 1
printf(&quot;%d\n&quot;, p[1]);    // 2
printf(&quot;%d\n&quot;, *(p+0));  // 1  — 포인터 연산
printf(&quot;%d\n&quot;, *(p+1));  // 2  — 포인터 연산</code></pre>
<h3 id="1포인터로-배열-중간부터-접근하기">1)포인터로 배열 중간부터 접근하기</h3>
<pre><code class="language-c">int *p = &amp;a[2];     // p가 a[2]를 가리킴
printf(&quot;%d\n&quot;, p[0]);  // 3  (a[2])
printf(&quot;%d\n&quot;, p[1]);  // 4  (a[3])</code></pre>
<h3 id="2함수-매개변수로-배열을-넘기면">2)함수 매개변수로 배열을 넘기면?</h3>
<pre><code class="language-c">void func(int arr[]) {
    arr[0] = -1;   // 원본 배열이 바뀐다!
    arr[1] = -2;
}

int main(void) {
    int a[5] = {1, 2, 3, 4, 5};
    func(a);
    printf(&quot;%d %d\n&quot;, a[0], a[1]);  // -1 -2
    return 0;
}</code></pre>
<blockquote>
<p>⚠️ <strong>함수 매개변수에 배열이 있으면 무조건 Call by Reference!</strong>
<code>arr[]</code>과 <code>*arr</code>은 표현만 다를 뿐 완전히 같은 의미다.</p>
</blockquote>
<h3 id="3표기법-비교">3)표기법 비교</h3>
<pre><code class="language-c">arr[i]      // 일반적인 표기 — 가독성 좋음 ✅
*(arr + i)  // 포인터 연산 표기 — 내부적으로 동일
arr[i] *= 2;        // 이것과
*(arr+i) = *(arr+i) * 2;  // 이것은 완전히 같다!</code></pre>

<h2 id="7-응용-코드내가-직접-해본-것들">7. 응용 코드(내가 직접 해본 것들)</h2>
<h3 id="문제-1-swap_ref로-배열-오름차순-정렬-버블정렬-적용">문제 1. swap_ref로 배열 오름차순 정렬 (버블정렬 적용)</h3>
<p>포인터 개념을 배우자마자 버블정렬에 적용해봤다.</p>
<pre><code class="language-c">#include &lt;stdio.h&gt;

void swap_ref(int *a, int *b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}

void bubbleSort(int arr[], int size) {
    for (int i = 0; i &lt; size - 1; i++) {
        for (int j = 0; j &lt; size - 1 - i; j++) {
            if (arr[j] &gt; arr[j + 1])
                swap_ref(&amp;arr[j], &amp;arr[j + 1]);  // 포인터 swap 활용!
        }
    }
}

int main(void) {
    int arr[5] = {5, 3, 1, 4, 2};

    bubbleSort(arr, 5);

    printf(&quot;정렬 결과: &quot;);
    for (int i = 0; i &lt; 5; i++)
        printf(&quot;%d &quot;, arr[i]);  // 1 2 3 4 5
    printf(&quot;\n&quot;);

    return 0;
}</code></pre>
<pre><code>버블정렬 동작 원리:
[5, 3, 1, 4, 2]
→ 5&gt;3 → swap → [3, 5, 1, 4, 2]
→ 5&gt;1 → swap → [3, 1, 5, 4, 2]
→ 5&gt;4 → swap → [3, 1, 4, 5, 2]
→ 5&gt;2 → swap → [3, 1, 4, 2, 5]
(한 라운드가 끝나면 가장 큰 수가 맨 뒤로 간다!)</code></pre><blockquote>
<p>포인터 swap을 함수로 분리하면 정렬 코드가 훨씬 깔끔해진다.</p>
</blockquote>
<hr />
<h3 id="문제-2-포인터로-최댓값과-최솟값을-동시에-구하기">문제 2. 포인터로 최댓값과 최솟값을 동시에 구하기</h3>
<p>반환값이 하나인 함수의 한계를 포인터로 극복했다.</p>
<pre><code class="language-c">#include &lt;stdio.h&gt;

// 반환값이 1개뿐인 함수는 최댓값만 반환 가능
// 포인터를 쓰면 최댓값 + 최솟값을 동시에 구할 수 있다!
void getMaxMin(int arr[], int size, int *max, int *min) {
    *max = arr[0];
    *min = arr[0];
    for (int i = 1; i &lt; size; i++) {
        if (arr[i] &gt; *max) *max = arr[i];
        if (arr[i] &lt; *min) *min = arr[i];
    }
}

int main(void) {
    int arr[5] = {50, 30, 80, 10, 60};
    int maxVal, minVal;

    getMaxMin(arr, 5, &amp;maxVal, &amp;minVal);

    printf(&quot;최댓값: %d\n&quot;, maxVal);  // 80
    printf(&quot;최솟값: %d\n&quot;, minVal);  // 10

    return 0;
}</code></pre>
<blockquote>
<p>포인터 덕분에 함수 하나로 두 가지 결과를 동시에 돌려받을 수 있다!</p>
</blockquote>

<h3 id="문제-3-call-by-value-vs-reference--직접-비교-실험">문제 3. Call by Value vs Reference — 직접 비교 실험</h3>
<pre><code class="language-c">#include &lt;stdio.h&gt;

void byValue(int x) {
    x = 999;
    printf(&quot;함수 내부 (value): %d\n&quot;, x);  // 999
}

void byReference(int *x) {
    *x = 999;
    printf(&quot;함수 내부 (ref): %d\n&quot;, *x);  // 999
}

int main(void) {
    int a = 1;

    byValue(a);
    printf(&quot;함수 후 (value): %d\n&quot;, a);  // 1 — 안 바뀜!

    byReference(&amp;a);
    printf(&quot;함수 후 (ref): %d\n&quot;, a);    // 999 — 바뀜!

    return 0;
}</code></pre>
<p>출력 결과:</p>
<pre><code>함수 내부 (value): 999
함수 후 (value): 1       ← 원본 유지
함수 내부 (ref): 999
함수 후 (ref): 999       ← 원본 변경됨!</code></pre><blockquote>
<p>이 실험 하나로 두 방식의 차이가 눈으로 확실히 보인다.</p>
</blockquote>
