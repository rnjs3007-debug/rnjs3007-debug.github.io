<h2 id="2-전체-코드">2. 전체 코드</h2>
<pre><code class="language-c">#include &quot;pch.h&quot;      // 컴파일 속도 향상 (미리 컴파일된 헤더)

{

    // Y축 눈금 출력 (50, 100 ... 500)

<h2 id="3-코드-분석">3. 코드 분석</h2>
<h3 id="easywin32란">EasyWin32란?</h3>
<p>일반 C언어로 윈도우 GUI를 만들려면 Win32 API가 엄청 복잡한데,<br /><code>tipsware.h</code>를 쓰면 <code>printf(x좌표, y좌표, &quot;텍스트&quot;)</code> 형태로 간단하게 화면에 출력할 수 있다.</p>
<p>기본 C 콘솔 <code>printf</code>랑 달리 <strong>위치를 직접 지정</strong>할 수 있는 게 핵심.</p>
<hr />
<h3 id="좌표-눈금-출력">좌표 눈금 출력</h3>
<pre><code class="language-c">for (int x = 0; x &lt; 16; x++) {
    printf(x * 50, 0, &quot;%d&quot;, x * 50);
}</code></pre>
<p>X축 방향으로 50 간격마다 숫자를 찍는다.<br /><code>x = 0</code> → 좌표 (0, 0)에 <code>&quot;0&quot;</code> 출력<br /><code>x = 1</code> → 좌표 (50, 0)에 <code>&quot;50&quot;</code> 출력<br />...이런 식으로 눈금자 역할을 한다.</p>
<p>Y축도 똑같이 <code>y * 50</code> 간격으로 찍어서 격자 기준점을 만든 것.</p>
<hr />
<h3 id="settextcolor-vs-printf에-rgb-직접-넣기">SetTextColor vs printf에 RGB 직접 넣기</h3>
<table>
<thead>
<tr>
<th>방식</th>
<th>설명</th>
</tr>
</thead>
<tbody><tr>
<td><code>SetTextColor(RGB(...))</code></td>
<td>이후 모든 텍스트에 색상 고정</td>
</tr>
<tr>
<td><code>printf(x, y, RGB(...), &quot;텍스트&quot;)</code></td>
<td>해당 출력만 그 색상으로 지정</td>
</tr>
</tbody></table>
<p><code>SetTextColor</code>는 <strong>전역 설정</strong>처럼 동작해서, 그 다음부터 출력되는 텍스트는 전부 그 색으로 찍힌다.<br />개별 색을 주고 싶으면 <code>printf</code>에 RGB를 직접 넣으면 된다.</p>
<hr />
<h3 id="그라데이션-효과-원리">그라데이션 효과 원리</h3>
<pre><code class="language-c">printf(100, 100, RGB(0,   0,   255), &quot;areum파일임!&quot;);
printf(95,  95,  RGB(10,  150, 150), &quot;areum파일임!&quot;);
printf(98,  98,  RGB(15,  16,  100), &quot;areum파일임!&quot;);
printf(94,  94,  RGB(2,   4,   50),  &quot;areum파일임!&quot;);</code></pre>
<p>같은 텍스트를 <strong>좌표를 1~5px씩 다르게</strong>, <strong>색상도 조금씩 다르게</strong> 해서 여러 번 출력한다.<br />텍스트가 겹쳐 보이면서 입체감이나 그라데이션처럼 보이는 효과가 생긴다.</p>
<p>포토샵 레이어 쌓는 것과 비슷한 원리라고 보면 됨.</p>
<hr />
<h3 id="showdisplay를-마지막에-쓰는-이유">ShowDisplay()를 마지막에 쓰는 이유</h3>
<p>EasyWin32는 <code>printf</code>를 호출해도 바로 화면에 그리지 않고 <strong>버퍼에 저장</strong>해둔다.<br /><code>ShowDisplay()</code>를 호출해야 비로소 화면에 한 번에 출력된다.</p>
<p>이걸 <strong>더블 버퍼링</strong>이라고 하는데, 화면이 깜빡이지 않고 부드럽게 출력되도록 하는 기법이다.<br />게임 개발이나 그래픽 프로그래밍에서 자주 쓰이는 개념.</p>
<hr />
<h2 id="4-마무리">4. 마무리</h2>
<ul>
<li>EasyWin32 <code>printf</code>는 좌표 + 색상을 직접 지정해서 출력할 수 있다</li>
<li><code>SetTextColor</code>는 전역, <code>printf</code> 안의 RGB는 지역 색상 지정</li>
<li>좌표를 살짝 다르게 해서 같은 텍스트를 여러 번 출력하면 그라데이션/입체 효과 가능</li>
<li><code>ShowDisplay()</code>는 버퍼에 쌓인 내용을 한 번에 화면에 뿌려주는 역할</li>
</ul>
