<h2 id="기본-개념">기본 개념</h2>
<h3 id="flex-container--flex-item">Flex Container &amp; Flex Item</h3>
<p>Flex는 <strong>부모-자식 관계</strong>로 작동한다. 부모 요소가 <strong>Flex Container</strong>, 자식 요소들이 <strong>Flex Item</strong>이다.</p>
<pre><code class="language-html">&lt;div class=&quot;container&quot;&gt;
  &lt;div class=&quot;item&quot;&gt;A&lt;/div&gt;
  &lt;div class=&quot;item&quot;&gt;B&lt;/div&gt;
  &lt;div class=&quot;item&quot;&gt;C&lt;/div&gt;
&lt;/div&gt;</code></pre>
<p>컨테이너가 Flex의 영향을 받는 전체 공간이고, 아이템들이 그 안에서 설정된 속성에 따라 배치된다.</p>
<p>Flex의 속성은 크게 두 가지로 나뉜다.</p>
<ul>
<li><strong>컨테이너에 적용하는 속성</strong></li>
<li><strong>아이템에 적용하는 속성</strong></li>
</ul>
<h3 id="메인축main-axis과-교차축cross-axis">메인축(Main Axis)과 교차축(Cross Axis)</h3>
<p>Flex에서 가장 중요한 개념이다.</p>
<ul>
<li><strong>메인축(Main Axis)</strong>: 아이템이 배치되는 방향의 축</li>
<li><strong>교차축(Cross Axis)</strong>: 메인축과 수직인 축</li>
</ul>
<blockquote>
<p>💡 <strong>정렬 키워드</strong></p>
<ul>
<li><code>justify-*</code> → 메인축 방향 정렬</li>
<li><code>align-*</code> → 교차축(수직축) 방향 정렬</li>
</ul>
</blockquote>
<p>이 규칙은 Grid에서도 그대로 이어지므로 반드시 기억해두자.</p>
<hr />
<h2 id="컨테이너에-적용하는-속성">컨테이너에 적용하는 속성</h2>
<h3 id="display-flex">display: flex</h3>
<p>컨테이너에 <code>display: flex</code>를 선언하면 Flex가 시작된다.</p>
<pre><code class="language-css">.container {
  display: flex;
  /* display: inline-flex; */
}</code></pre>
<p><code>display: flex</code>를 적용하면 아이템들은 <strong>가로 방향</strong>으로 배치되고, 각자의 컨텐츠 너비만큼만 차지한다. 높이는 컨테이너 높이만큼 자동으로 늘어난다.</p>
<p><code>inline-flex</code>는 컨테이너 자체가 inline-block처럼 동작하게 한다. 아이템 배치 방식이 아닌, 컨테이너가 주변 요소들과 어우러지는 방식의 차이다.</p>
<hr />
<h3 id="flex-direction--배치-방향-설정">flex-direction — 배치 방향 설정</h3>
<p>메인축의 방향(가로 or 세로)을 결정한다.</p>
<pre><code class="language-css">.container {
  flex-direction: row;          /* 기본값, 가로 */
  /* flex-direction: row-reverse;    역순 가로 */
  /* flex-direction: column;         세로 */
  /* flex-direction: column-reverse; 역순 세로 */
}</code></pre>
<table>
<thead>
<tr>
<th>값</th>
<th>설명</th>
</tr>
</thead>
<tbody><tr>
<td><code>row</code></td>
<td>아이템들이 가로(왼→오) 방향으로 배치 (기본값)</td>
</tr>
<tr>
<td><code>row-reverse</code></td>
<td>아이템들이 역순으로 가로 배치 (오→왼)</td>
</tr>
<tr>
<td><code>column</code></td>
<td>아이템들이 세로(위→아래) 방향으로 배치</td>
</tr>
<tr>
<td><code>column-reverse</code></td>
<td>아이템들이 역순으로 세로 배치 (아래→위)</td>
</tr>
</tbody></table>
<blockquote>
<p>💡 반응형 레이아웃 활용 팁: 모바일에서는 <code>column</code>, 일정 너비 이상에서는 <code>row</code>로 전환하면 반응형 구현이 편리하다.</p>
</blockquote>
<hr />
<h3 id="flex-wrap--줄넘김-처리">flex-wrap — 줄넘김 처리</h3>
<p>컨테이너에 공간이 부족할 때 아이템을 어떻게 처리할지 결정한다.</p>
<pre><code class="language-css">.container {
  flex-wrap: nowrap;       /* 기본값, 줄바꿈 없음 (삐져나감) */
  /* flex-wrap: wrap;         줄바꿈 */
  /* flex-wrap: wrap-reverse; 역순으로 줄바꿈 */
}</code></pre>
<table>
<thead>
<tr>
<th>값</th>
<th>설명</th>
</tr>
</thead>
<tbody><tr>
<td><code>nowrap</code></td>
<td>줄바꿈 없음. 넘치면 그냥 삐져나감 (기본값)</td>
</tr>
<tr>
<td><code>wrap</code></td>
<td>넘치면 다음 줄로 줄바꿈</td>
</tr>
<tr>
<td><code>wrap-reverse</code></td>
<td>줄바꿈하되, 아이템을 역순으로 배치</td>
</tr>
</tbody></table>
<hr />
<h3 id="flex-flow--단축-속성">flex-flow — 단축 속성</h3>
<p><code>flex-direction</code>과 <code>flex-wrap</code>을 한 번에 쓸 수 있는 단축 속성.</p>
<pre><code class="language-css">.container {
  flex-flow: row wrap;
  /* flex-direction: row; + flex-wrap: wrap; 의 단축형 */
}</code></pre>
<hr />
<h3 id="justify-content--메인축-정렬">justify-content — 메인축 정렬</h3>
<p><code>justify</code> = 메인축 방향 정렬. 아이템들을 메인축을 따라 어떻게 배치할지 결정.</p>
<pre><code class="language-css">.container {
  justify-content: flex-start;    /* 기본값 */
  /* justify-content: flex-end;      */
  /* justify-content: center;        */
  /* justify-content: space-between; */
  /* justify-content: space-around;  */
  /* justify-content: space-evenly;  */
}</code></pre>
<table>
<thead>
<tr>
<th>값</th>
<th>설명</th>
</tr>
</thead>
<tbody><tr>
<td><code>flex-start</code></td>
<td>시작점(row:왼쪽, column:위) 정렬 (기본값)</td>
</tr>
<tr>
<td><code>flex-end</code></td>
<td>끝점(row:오른쪽, column:아래) 정렬</td>
</tr>
<tr>
<td><code>center</code></td>
<td>가운데 정렬</td>
</tr>
<tr>
<td><code>space-between</code></td>
<td>아이템 사이에 균일한 간격</td>
</tr>
<tr>
<td><code>space-around</code></td>
<td>아이템 둘레에 균일한 간격 (양 끝은 절반)</td>
</tr>
<tr>
<td><code>space-evenly</code></td>
<td>아이템 사이와 양 끝 모두 균일한 간격 ⚠️ IE/Edge 미지원</td>
</tr>
</tbody></table>
<hr />
<h3 id="align-items--교차축-정렬">align-items — 교차축 정렬</h3>
<p><code>align</code> = 교차축(수직축) 방향 정렬. <code>justify-content</code>의 수직 버전이라고 생각하면 됨.</p>
<pre><code class="language-css">.container {
  align-items: stretch;      /* 기본값 */
  /* align-items: flex-start; */
  /* align-items: flex-end;   */
  /* align-items: center;     */
  /* align-items: baseline;   */
}</code></pre>
<table>
<thead>
<tr>
<th>값</th>
<th>설명</th>
</tr>
</thead>
<tbody><tr>
<td><code>stretch</code></td>
<td>수직축 방향으로 끝까지 늘어남 (기본값)</td>
</tr>
<tr>
<td><code>flex-start</code></td>
<td>시작점(row:위, column:왼쪽) 정렬</td>
</tr>
<tr>
<td><code>flex-end</code></td>
<td>끝점(row:아래, column:오른쪽) 정렬</td>
</tr>
<tr>
<td><code>center</code></td>
<td>수직 가운데 정렬</td>
</tr>
<tr>
<td><code>baseline</code></td>
<td>텍스트 베이스라인 기준 정렬</td>
</tr>
</tbody></table>
<blockquote>
<p>💡 완전 가운데 정렬은 <code>justify-content: center</code> + <code>align-items: center</code> 조합으로 쉽게 구현!</p>
</blockquote>
<hr />
<h3 id="align-content--여러-행-교차축-정렬">align-content — 여러 행 교차축 정렬</h3>
<p><code>flex-wrap: wrap</code>으로 아이템이 <strong>2줄 이상</strong>이 되었을 때, 행들의 교차축 방향 정렬을 결정한다. 1줄일 때는 효과 없음.</p>
<pre><code class="language-css">.container {
  flex-wrap: wrap;
  align-content: stretch;
  /* stretch / flex-start / flex-end / center */
  /* space-between / space-around / space-evenly */
}</code></pre>
<blockquote>
<p>⚠️ <code>space-evenly</code>는 IE와 구버전 Edge에서 지원되지 않으므로 주의.</p>
</blockquote>
<hr />
<h2 id="아이템에-적용하는-속성">아이템에 적용하는 속성</h2>
<h3 id="flex-basis--기본-크기-설정">flex-basis — 기본 크기 설정</h3>
<p>아이템의 기본 점유 크기. <code>flex-direction: row</code>일 때는 너비, <code>column</code>일 때는 높이로 작동.</p>
<pre><code class="language-css">.item {
  flex-basis: auto;    /* 기본값: 아이템의 width값 사용 */
  /* flex-basis: 0;      */
  /* flex-basis: 50%;    */
  /* flex-basis: 300px;  */
}</code></pre>
<p><code>flex-basis: auto</code>는 아이템의 <code>width</code> 값을 따른다. <code>width</code>를 따로 설정하지 않으면 컨텐츠 크기가 된다.</p>
<p><code>width</code>와의 차이: <code>flex-basis</code>는 원래 크기보다 작아지지 않지만, <code>width</code>는 강제로 줄인다.</p>
<hr />
<h3 id="flex-grow--유연하게-늘리기">flex-grow — 유연하게 늘리기</h3>
<p>아이템이 <code>flex-basis</code>보다 커질 수 있는지 결정. <code>0</code>보다 큰 값이면 남은 여백을 비율대로 나눠 가진다. 기본값 <code>0</code>.</p>
<pre><code class="language-css">.item { flex-grow: 1; }

/* 1:2:1 비율로 여백 나누기 */
.item:nth-child(1) { flex-grow: 1; }
.item:nth-child(2) { flex-grow: 2; }
.item:nth-child(3) { flex-grow: 1; }</code></pre>
<blockquote>
<p>💡 <code>flex-grow</code>의 숫자는 <strong>여백을 나누는 비율</strong>이다. 아이템 자체의 크기가 다르면 결과도 미묘하게 달라 보일 수 있다. 영역 자체를 정확한 비율로 나누려면 <code>flex-basis: 0</code>과 함께 사용하자.</p>
</blockquote>
<hr />
<h3 id="flex-shrink--유연하게-줄이기">flex-shrink — 유연하게 줄이기</h3>
<p>아이템이 <code>flex-basis</code>보다 작아질 수 있는지 결정. 기본값 <code>1</code>이므로 기본적으로 줄어들 수 있다.</p>
<pre><code class="language-css">.item {
  flex-basis: 150px;
  flex-shrink: 1; /* 기본값 */
}

/* 고정 폭 + 나머지 자동 채우기 레이아웃 */
.item:nth-child(1) {
  flex-shrink: 0;  /* 절대 줄어들지 않음 */
  width: 100px;
}
.item:nth-child(2) {
  flex-grow: 1;    /* 나머지 공간 모두 차지 */
}</code></pre>
<p><code>flex-shrink: 0</code>을 이용하면 컨테이너가 아무리 작아져도 해당 아이템은 지정 크기를 유지하는 <strong>고정 폭 컬럼</strong>을 쉽게 만들 수 있다.</p>
<hr />
<h3 id="flex--grow-shrink-basis-단축-속성">flex — grow, shrink, basis 단축 속성</h3>
<p>세 속성이 서로 연관되어 있으므로 단축 속성 <code>flex</code>를 쓰는 게 권장된다.</p>
<pre><code class="language-css">.item {
  flex: 1;
  /* flex-grow: 1; flex-shrink: 1; flex-basis: 0%; */

  flex: 1 1 auto;
  /* flex-grow: 1; flex-shrink: 1; flex-basis: auto; */

  flex: 1 500px;
  /* flex-grow: 1; flex-shrink: 1; flex-basis: 500px; */
}</code></pre>
<blockquote>
<p>⚠️ <code>flex: 1</code>처럼 <code>flex-basis</code>를 생략하면 <code>flex-basis: 0%</code>가 된다. <code>auto</code>가 아님에 주의!</p>
</blockquote>
<p>영역 자체를 정확한 비율로 나누고 싶을 때:</p>
<pre><code class="language-css">.item              { flex: 1 1 0; } /* 1 비율 */
.item:nth-child(2) { flex: 2 1 0; } /* 2 비율 */</code></pre>
<p><code>flex-basis: 0</code>으로 기본 점유 크기를 0으로 만들어 전체를 정확히 <code>1:2:1</code>로 분할.</p>
<p><strong>2단 컬럼 리스트 예시:</strong></p>
<pre><code class="language-css">.container {
  display: flex;
  flex-wrap: wrap;
}
.item {
  flex: 1 1 40%; /* 한 줄에 최대 2개 */
  /* flex: 1 1 30% → 3단 컬럼 */
}</code></pre>
<hr />
<h3 id="align-self--개별-아이템-교차축-정렬">align-self — 개별 아이템 교차축 정렬</h3>
<p><code>align-items</code>의 개별 아이템 버전. 컨테이너의 <code>align-items</code> 설정을 오버라이드한다.</p>
<pre><code class="language-css">.item {
  align-self: auto;       /* 기본값: align-items 상속 */
  /* align-self: stretch;    */
  /* align-self: flex-start; */
  /* align-self: flex-end;   */
  /* align-self: center;     */
  /* align-self: baseline;   */
}</code></pre>
<blockquote>
<p>💡 개별 설정이 전체 설정보다 우선된다. <code>align-self</code> &gt; <code>align-items</code>.</p>
</blockquote>
<hr />
<h3 id="order--배치-순서">order — 배치 순서</h3>
<p>아이템의 시각적 배치 순서를 지정. 숫자가 작을수록 앞에 배치된다.</p>
<pre><code class="language-css">.item:nth-child(1) { order: 3; } /* A → 3번째 */
.item:nth-child(2) { order: 1; } /* B → 1번째 */
.item:nth-child(3) { order: 2; } /* C → 2번째 */</code></pre>
<blockquote>
<p>⚠️ <code>order</code>는 <strong>시각적 순서</strong>만 바꾸고 HTML 구조는 유지된다. 스크린 리더는 HTML 순서대로 읽으므로 접근성에 주의해야 한다.</p>
</blockquote>
<hr />
<h3 id="z-index--z축-정렬">z-index — Z축 정렬</h3>
<p><code>position</code>에서의 <code>z-index</code>와 동일하게 동작한다. 숫자가 클수록 위로 올라온다.</p>
<pre><code class="language-css">.item:nth-child(2) {
  z-index: 1;
  transform: scale(2);
}
/* 설정 안 하면 기본값 0, 1만 설정해도 나머지보다 위로 올라옴 */</code></pre>
<hr />
<h2 id="전체-속성-한눈에-정리">전체 속성 한눈에 정리</h2>
