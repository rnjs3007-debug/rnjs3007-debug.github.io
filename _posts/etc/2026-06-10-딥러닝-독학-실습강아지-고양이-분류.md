<h2 id="3-원인은-무엇일까">3. 원인은 무엇일까?</h2>
<p>처음엔 그냥 &quot;내가 뭔가 잘못했나?&quot; 싶었는데, 찾아보니까 이유가 꽤 여러 가지였다.</p>
<h3 id="1-학습-데이터가-충분하지-않았을-수-있다">1) 학습 데이터가 충분하지 않았을 수 있다</h3>
<p>딥러닝 모델은 데이터를 많이 봐야 제대로 학습한다.
데이터가 적거나 특정 클래스에 치우쳐 있으면 편향된 예측을 한다.</p>
<h3 id="2-에포크epoch가-너무-적거나-많았을-수-있다">2) 에포크(epoch)가 너무 적거나 많았을 수 있다</h3>
<p>학습을 너무 적게 하면 → <strong>underfitting</strong> (아직 덜 배운 상태)<br />학습을 너무 많이 하면 → <strong>overfitting</strong> (훈련 데이터만 외운 상태)</p>
<p>두 경우 모두 새로운 이미지에서 틀릴 수 있다.</p>
<h3 id="3-레이블-기준-문제">3) 레이블 기준 문제</h3>
<p>이진 분류에서 <code>0 = cat</code>, <code>1 = dog</code> 이런 식으로 레이블을 정하는데,<br />출력값 해석할 때 반대로 읽으면 결과가 뒤집힌다.</p>
<p>예를 들어 <code>sigmoid</code> 출력이 <strong>0.3</strong> 이면 → <code>cat</code><br />이걸 <code>&gt;0.5 이면 dog</code>로 처리해야 하는데 반대로 처리하면 강아지가 고양이로 나온다.</p>
<h3 id="4-이미지-전처리-불일치">4) 이미지 전처리 불일치</h3>
<p>학습할 때 이미지를 <code>0~1</code>로 정규화했는데,<br />예측할 때 정규화를 안 했다면? → 모델이 전혀 다른 분포의 입력을 받는 거라 틀릴 수밖에 없다.</p>
<hr />
<h2 id="4-직접-확인해본-코드">4. 직접 확인해본 코드</h2>
<pre><code class="language-python"># 예측 부분 - 이렇게 처리했었음
img = tf.keras.utils.load_img('dog.jpg', target_size=(150, 150))
img_array = tf.keras.utils.img_to_array(img)
img_array = img_array / 255.0  # 정규화 (이거 빠뜨리면 바로 틀림)
img_array = np.expand_dims(img_array, axis=0)

prediction = model.predict(img_array)
print(&quot;cat&quot; if prediction[0][0] &lt; 0.5 else &quot;dog&quot;)</code></pre>
<p>레이블 방향이랑 정규화 두 개가 핵심이었다.</p>
